# Vanilla profile

The minimal baseline. It keeps the plain OpenCode experience: built-in agents,
the globally selected model, and no custom agents or skills.

## Managed entries

- `AGENTS.md`: short team guidance
- `opencode.json`: only the shared Context7 MCP server
- `agents/` and `skills/`: intentionally empty

Use it as the starting point for a new profile, or install it to go back to a
plain setup. The installer preselects this profile.
